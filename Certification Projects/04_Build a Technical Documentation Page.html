Introduction

Flexbox is a one-dimensional layout model that offers powerful space distribution and alignment capabilities. Unlike block and inline layouts, flexbox works with a flex container and its flex items.

The main idea is to give the container the ability to alter its items' width, height, and order to best fill the available space. Flexbox is great for responsive design and simplifies many common layout patterns.

Flexbox has two axes: the main axis and the cross axis. The main axis is defined by the flex-direction property, while the cross axis runs perpendicular to it.

display: flex; /* or inline-flex */

To start using flexbox, you simply set display: flex on a container element. All its direct children become flex items.

  • Flex items are laid out along the main axis.
  • The container can control wrapping, alignment, and ordering.
  • Flexbox is ideal for UI components like navigation bars, cards, and forms.
Flex Container

The flex container is the parent element with display: flex or display: inline-flex. It establishes the flex formatting context for its children.

Important properties for the container include flex-direction, flex-wrap, justify-content, align-items, and align-content.

flex-direction defines the main axis direction: row, row-reverse, column, column-reverse.

flex-direction: row; /* default */

flex-wrap controls whether items wrap onto multiple lines: nowrap, wrap, wrap-reverse.

flex-wrap: wrap;
  • flex-flow is a shorthand for flex-direction and flex-wrap.
  • Example: flex-flow: row wrap;
Flex Items

Flex items are direct children of a flex container. They can be sized and ordered independently.

Key properties for items are flex-grow, flex-shrink, flex-basis, and the shorthand flex.

flex-grow defines how much the item will grow relative to others. Default is 0.

flex-grow: 1; /* takes up remaining space */

flex-shrink defines how the item shrinks if space is tight.

flex-shrink: 1; /* default */
  • flex-basis sets the initial main size of the item.
  • The shorthand flex: 1 1 auto; means grow, shrink, and base size auto.
  • order changes the visual order of items without affecting source order.
Alignment

Alignment in flexbox is achieved through several properties that work on both axes.

justify-content aligns items along the main axis. Possible values: flex-start, flex-end, center, space-between, space-around, space-evenly.

justify-content: center;

align-items aligns items along the cross axis. Values: stretch, flex-start, flex-end, center, baseline.

align-items: stretch; /* default */

align-self allows an individual item to override the container's align-items.

align-self: flex-end;
  • Use align-content to align multiple lines of items (when wrapping).
  • It works like justify-content but on the cross axis.
Practical Examples

Here are some common use cases for flexbox in real projects.

Navigation bar: Use display: flex on the <nav> to distribute links evenly.

nav { display: flex; justify-content: space-around; }

Card layout: Use flex-wrap: wrap and flex: 1 1 200px; on cards to create responsive grid.

.cards { display: flex; flex-wrap: wrap; }

Centering a div: Combine justify-content: center and align-items: center.

.center { display: flex; justify-content: center; align-items: center; height: 100vh; }
  • Flexbox is widely supported in all modern browsers.
  • It's a fundamental tool for CSS layouts today.
